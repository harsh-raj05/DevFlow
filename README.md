✨ Features & Interactive Experiences
DevFlow is not a static mockup. Every section provides authentic, responsive interactions:

1. 🌌 Atmospheric & Dynamic Particle Canvas
Interactive 60 FPS HTML5 Canvas particle mesh that reacts dynamically to cursor velocity with glowing proximity threads.
Multi-layer aurora radial gradients, dark cybernetic grids, and scanline textures.
2. ⚡ Live Hero Command Center
Interactive Multi-Tab Window: Switch between Overview, Git & PRs, and Focus Sprint modes.
Dynamic Timeframe Selector: Toggle Today, 7 Days, or Sprint to recalculate velocity metrics and commit charts.
Interactive Commit Velocity Chart: Hover over individual bars to inspect exact commit timestamps and contributions.
Live Branch Status: Real-time branch status indicators with clean Git head badges.
3. 🎯 Focus Sprint Workbench & Pomodoro Timer
Live Task Management: Add custom tasks, delete tasks, and filter by category (Project, Learning, Architecture).
Celebratory Micro-Interactions: Checking off tasks updates sprint progress meters with smooth completion animations.
Working Pomodoro Timer: Integrated 25-minute deep focus sprint timer with Start, Pause, and Reset controls.
Local-First Persistence: Tasks and progress states persist in localStorage across page reloads.
4. 🔀 Workflow Architecture Comparison
Interactive toggle comparing "The Fragmented Chaos" (15 open tabs, lost context, heavyweight SaaS lag) against "The DevFlow Unified Engine" (Single pane, sub-4ms response, zero friction).
5. 🛠️ Interactive Feature Micro-Demos
Git-Native Worktrees: Live branch switcher (main, feat/auth-v2, perf/render-mesh) showing instant reactive state changes.
Commit Density Heatmap: GitHub-style contribution matrix with hover block inspector.
Deep Work Zen Mode: Interactive toggle simulating distraction-free focus mode.
6. 🧮 Interactive Context-Switch Tax Calculator
Mathematical model allowing developers to adjust sliders (Active Projects, Daily Tools Switched, Coding Hours) to calculate exact cognitive tax hours lost and deep-work hours recovered.
7. ⌨️ Global Command Palette (Cmd+K / Ctrl+K)
Spotlight command bar with keyboard arrow navigation, quick search filtering, section jumping, and terminal shortcuts.
8. 🛡️ The Honest Developer Manifesto
Strict Honesty Compliance: 100% adherence to the challenge requirement — 0 fake testimonials, 0 fabricated user counts, and 0 fake logos. Pure focus on speed, privacy, and local-first architecture.

Unlock via Konami Code (↑ ↑ ↓ ↓ ← → ← → B A), pressing the ~ (tilde) key, or clicking the floating CLI button in the bottom right corner.

🛠️ Tech Stack & Architecture
Core: React 19 + Vite 8
Styling: Tailwind CSS v4 + Custom Glassmorphism Tokens
Animations: Framer Motion v13 (restrained, 60fps micro-interactions)
Icons: Lucide React (pure SVG tree-shaken)
State & Storage: React Hooks + Local-First Client Storage
Canvas: Native HTML5 Canvas 2D Context
🚀 Getting Started Locally
Prerequisites
Node.js 18+ (Node.js 20+ recommended)
npm, yarn, or pnpm
Installation
# Clone the repository
git clone https://github.com/your-username/devflow.git

# Navigate to the project directory
cd devflow

# Install dependencies
npm install

# Start the local development server
npm run dev
The application will be running at http://localhost:5173/.

Production Build
# Build the optimized production bundle
npm run build

# Preview the production build locally
npm run preview
